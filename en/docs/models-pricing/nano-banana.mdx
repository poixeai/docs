Nano Banana is Google's family of Gemini AI image generation models. It supports generating and editing images conversationally using text, images, or a combination of both.

The family includes three main models:

| Model alias       | Official model name          | Positioning                          |
| ----------------- | ---------------------------- | ------------------------------------ |
| `nano-banana`     | `gemini-2.5-flash-image`     | Speed first: high throughput, low latency |
| `nano-banana-pro` | `gemini-3-pro-image-preview` | Quality first: supports 4K and advanced text rendering |
| `nano-banana-2` | `gemini-3.1-flash-image-preview` | Optimized for speed and large-scale usage |

<Callout type="info" icon="info-circle">
  Poixe supports calling models by either **model alias** or **official native model name**.
  Aliases are only internal mappings. If the official models are later updated or replaced, we may adjust the alias mappings accordingly to keep them working.
</Callout>

## Model comparison

| Feature      | Nano Banana | Nano Banana Pro | Nano Banana 2 |
| ------------ | ----------- | ------------------------------ | ------------- |
| Generation speed | ~10 s | ~20 s | ~8 s |
| Max resolution | 1024×1024 (1K) | 4096×4096 (4K) | 4096×4096 (4K) |
| Text rendering | Basic | Excellent | Good |
| Reference images | Up to 3 | Up to 14 | Up to 14 |
| Reasoning    | Standard | Advanced | Standard+ |
| Local editing | Basic | Advanced | Intermediate |

**Recommendations**:

- Fast image output, general scenarios → `nano-banana`
- High clarity, text rendering, professional design → `nano-banana-pro`
- Lower cost and higher concurrency → `nano-banana-2`

### Request example

```bash
curl "https://api.poixe.com/v1beta/models/gemini-3-pro-image-preview:generateContent" \
  -H "x-goog-api-key: $POIXE_API_KEY" \
  -H "Content-Type: application/json" \
  -X POST \
  -d '{
    "contents": [
      {
        "parts": [
          {
            "text": "An orange tabby cat sitting on a windowsill watching the rain, cyberpunk style"
          }
        ]
      }
    ],
    "generationConfig": {
      "responseModalities": ["Text", "Image"],
      "imageConfig": {
        "aspectRatio": "16:9",
        "imageSize": "2K"
      }
    }
  }'
```

## Parameters

### Output type

Use `responseModalities` to control what is returned:

```json
{
  "generationConfig": {
    "responseModalities": ["Image"] // Return only the image, no text
  }
}
```

Supported values: `Text`, `Image`

### Aspect ratio

Use `imageConfig.aspectRatio` to set the frame:

```json
{
  "generationConfig": {
    "imageConfig": {
      "aspectRatio": "16:9" // Set the aspect ratio to 16:9
    }
  }
}
```

Supported aspect ratios: `1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`, `21:9`

### Resolution

Supported output resolutions:

```json
{
  "generationConfig": {
    "imageConfig": {
      "aspectRatio": "16:9",
      "imageSize": "4K" // Set the resolution to 4K
    }
  }
}
```

Supported resolutions: `1K` (1024x1024), `2K` (2048x2048), `4K` (4096x4096)

## Nano Banana Pro exclusive features

`nano-banana-pro` (`gemini-3-pro-image-preview`) offers the following advanced features:

- **4K HD output**: supports three resolution levels: 1K/2K/4K
- **Advanced text rendering**: suited for infographics, menus, marketing assets, and similar scenarios
- **Thinking mode**: the model first generates draft concept images, then outputs the final high-quality image
- **Multi-reference blending**: supports up to 14 reference images (including 6 high-fidelity object images + 5 person images)
- **Google Search grounding**: generate images based on real-time data (weather, stocks, etc.)

## Nano Banana 2 exclusive features

`nano-banana-2` (`gemini-3.1-flash-image-preview`) delivers high-quality image generation and conversational editing at a mainstream price, with lower latency and higher throughput. It is an efficient counterpart to `nano-banana-pro`, optimized for speed-sensitive and high-concurrency scenarios.

**Key updates:**

- **New resolution options**: supports `0.5K / 1K / 2K / 4K` (default 1K)
- **Enhanced real-time search**: combines text and image search results to give generation real-time information
- **Controllable thinking mode**: the thinking phase can be turned on or off
- **New aspect ratios**: supports `1:4`, `4:1`, `1:8`, `8:1`
- **Better aspect ratio adherence**: output framing is more stable
- **Improved image quality and consistency**
- **Improved multilingual text rendering (i18n)**

## Limitations

- Best-supported languages: English, Chinese, Japanese, Korean, French, German, Spanish, and other major languages
- Audio and video input are not supported
- All generated images include a [SynthID watermark](https://ai.google.dev/responsible/docs/safeguards/synthid?hl=zh-cn)
- Text rendering tip: first have the model generate the text content, then ask it to generate an image containing that text

## FAQ

<AccordionGroup>
  <Accordion title="Which version should I choose?">
    - Fast image output, general scenarios → `nano-banana` or `gemini-2.5-flash-image`
    - HD output, text rendering, professional design → `nano-banana-pro` or `gemini-3-pro-image-preview`
    - High-concurrency batch generation or cost-sensitive scenarios → `nano-banana-2` or `gemini-3.1-flash-image-preview`
  </Accordion>

<Accordion title="What is the difference between nano-banana and gemini-2.5-flash-image?">
  None. `nano-banana` is an alias mapping within Poixe; the model actually called is
  `gemini-2.5-flash-image`.
  
  Likewise, `nano-banana-pro` maps to `gemini-3-pro-image-preview`, and they are the same model.
  
  For stability, we recommend using the official model names directly.
</Accordion>

<Accordion title="What format are the generated images?">
  Images are returned as base64-encoded data, usually PNG or JPEG, ready to use once decoded.
</Accordion>

<Accordion title="Is image editing supported?">
  Yes. You can upload images and edit them conversationally. Nano Banana Pro has stronger local editing capabilities.
</Accordion>

  <Accordion title="Why does the number of generated images not match my request?">
    The model does not always generate exactly the number of images requested. This is a known limitation of the model.
  </Accordion>
</AccordionGroup>

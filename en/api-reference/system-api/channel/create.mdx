Asynchronously create one or more channels. Returns a task ID immediately — poll [Task Status](/en/api-reference/system-api/channel/task) for the result.

<Callout type="warning" icon="triangle-exclamation">
  The `keys` field must contain pre-encrypted ciphertext in `enc:v2:...` format. **Plaintext API Keys are not accepted.** Use the [encryption tools](/en/docs/vendor/key-security#encryption-tools--examples) to encrypt locally first.
</Callout>

<ParamField body="keys" type="array" required>
  List of pre-encrypted API Keys, each an `enc:v2:...` ciphertext string, 1–100 items
</ParamField>

<ParamField body="price" type="number" required>
  Price multiplier — must be a valid value from the `prices` list returned by `/api/channels/pricing-options`
</ParamField>

<ParamField body="comment" type="string">
  Optional label stored with every channel in this batch
</ParamField>

<ParamField body="base_url" type="string">
  Required for Azure channel types. Full endpoint URL, must end with `.azure.com`. All keys in a single request must share the same `base_url` — submit separate requests for keys on different Azure endpoints
</ParamField>

<ParamField body="aws_region" type="string">
  AWS types only. Defaults to `eu-central-1`. Valid values: `eu-central-1` · `eu-west-1` · `eu-west-2` · `us-east-1` · `us-east-2` · `us-west-2`
</ParamField>

## Key Format by Type

| Type | Key content |
|---|---|
| Most types | Standard API key string |
| `aws_platform_claude` | `"workspace_id api_key"` (space-separated, encrypted as one string) |
| `google_vertex_gemini` | SA mode: full service account JSON; API key mode: `AIza...` string |

## Response Fields

</ResponseField>

</ResponseField>

## Errors

| Condition | HTTP | type |
|---|---|---|
| Invalid type slug | 400 | `invalid_request_error` |
| Key not an `enc:v2:` envelope | 400 | `invalid_request_error` |
| Azure: missing or invalid `base_url` | 400 | `invalid_request_error` |
| AWS: invalid `aws_region` | 400 | `invalid_request_error` |
| Duplicate key detected by egress | 400 | `invalid_request_error` |
| Channel count limit exceeded | 429 | `rate_limit_error` |

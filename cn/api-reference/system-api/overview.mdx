系统接口用于程序化管理账户、令牌、渠道与收益数据，使用**系统令牌**（System Token）进行鉴权。

<Callout type="warning" icon="triangle-exclamation">
  系统接口（`sys.poixe.com`）与调用模型的接口（`api.poixe.com`）是两套独立的服务，令牌类型也不同，请注意区分。
</Callout>

## 与其他接口的区别

| | 系统接口 | 文本接口 / 扩展接口 |
|---|---|---|
| **用途** | 账户管理、渠道管理、收益查询 | 调用模型、扩展功能 |
| **域名** | `https://sys.poixe.com` | `https://api.poixe.com` |
| **令牌** | 系统令牌 | 业务令牌 |

## 鉴权

所有系统接口请求都需要在 HTTP Header 中携带系统令牌：

```text
Authorization: Bearer YOUR_SYSTEM_TOKEN
```

业务令牌**不能**用于系统接口。系统令牌可在 [系统令牌管理页面](https://poixe.com/setting/system) 创建，详见 [系统令牌](/cn/docs/dashboard/system-tokens)。

## 分页

支持分页的列表接口通过 Query 参数控制：

| 参数 | 默认值 | 最大值 | 说明 |
|---|---|---|---|
| `page` | `1` | — | 页码（从 1 开始） |
| `page_size` | `20` | `100` | 每页条数 |

列表响应结构：

```json
{
  "total": 42,
  "page": 1,
  "page_size": 20,
  "items": [...],
  "timestamp": 1731337200
}
```

## 速率限制

| 层级 | 范围 | 限制 |
|---|---|---|
| 全局 | 每个用户（所有路由） | 120 RPM |
| 全局 | 每个 IP（所有路由） | 120 RPM |
| 路由级 | 见各接口说明 | 各不相同 |

超出限制返回 `429 rate_limit_error`。

## 通用错误格式

```json
{
  "error": {
    "type": "invalid_request_error",
    "message": "ids must be a non-empty array of channel IDs"
  }
}
```

| 状态码 | type | 说明 |
|---|---|---|
| `400` | `invalid_request_error` | 请求参数有误 |
| `401` | `forbidden_error` | 令牌无效、已过期或已禁用 |
| `403` | `forbidden_error` | 权限不足 |
| `404` | `resource_not_found_error` | 资源不存在 |
| `429` | `rate_limit_error` | 超出速率限制 |
| `500` | `internal_error` | 服务内部错误 |

所有货币字段单位为 **USD**，精确到 **3 位小数**。

Look up a token's ID by its key value (the `sk-` string). The key must belong to the calling account.

## Request Body

<ParamField body="key" type="string" required>
  Token key — must start with `sk-` and belong to the current account
</ParamField>

## Response Fields

<ResponseField name="id" type="integer">
  Token ID
</ResponseField>

<ResponseField name="timestamp" type="integer">
  Response timestamp (Unix seconds)
</ResponseField>

## Errors

| Condition | HTTP | type |
|---|---|---|
| `key` missing or empty | 400 | `invalid_request_error` |
| `key` does not start with `sk-` | 400 | `invalid_request_error` |
| Key not found or belongs to another account | 404 | `resource_not_found_error` |

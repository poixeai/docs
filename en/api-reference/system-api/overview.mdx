The System API is used to programmatically manage accounts, tokens, channels, and earnings data. All requests are authenticated using a **System Token**.

<Callout type="warning" icon="triangle-exclamation">
  The System API (`sys.poixe.com`) and the model inference API (`api.poixe.com`) are two separate services with different token types. Do not mix them up.
</Callout>

## Comparison with Other APIs

| | System API | Inference / Extension API |
|---|---|---|
| **Purpose** | Account management, channel management, earnings | Model inference, extended features |
| **Domain** | `https://sys.poixe.com` | `https://api.poixe.com` |
| **Token** | System token (`sys-` prefix) | Business token (`sk-` prefix) |

## Authentication

All System API requests require a system token in the HTTP Authorization header:

```text
Authorization: Bearer sys-xxxxxxxxxxxxxxxx
```

System tokens must start with `sys-`. Business tokens (`sk-` prefix) **cannot** be used with the System API. System tokens can be created on the [System Token settings page](https://poixe.com/setting/system). See [System Tokens](/en/docs/dashboard/system-tokens) for details.

## Pagination

List endpoints that support pagination are controlled via query parameters:

| Parameter | Default | Max | Description |
|---|---|---|---|
| `page` | `1` | — | Page number (1-indexed) |
| `page_size` | `20` | `100` | Items per page |

List response structure:

```json
{
  "total": 42,
  "page": 1,
  "page_size": 20,
  "items": [...],
  "timestamp": 1731337200
}
```

## Rate Limits

| Level | Scope | Limit |
|---|---|---|
| Global | Per user (all routes) | 120 RPM |
| Global | Per IP (all routes) | 120 RPM |
| Per-route | See individual endpoint docs | Varies |

Exceeding the limit returns `429 rate_limit_error`.

## Common Error Format

```json
{
  "error": {
    "type": "invalid_request_error",
    "message": "ids must be a non-empty array of channel IDs"
  }
}
```

| Status | type | Description |
|---|---|---|
| `400` | `invalid_request_error` | Invalid request parameters |
| `401` | `forbidden_error` | Token invalid, expired, or disabled |
| `403` | `forbidden_error` | Insufficient permissions |
| `404` | `resource_not_found_error` | Resource not found |
| `429` | `rate_limit_error` | Rate limit exceeded |
| `500` | `internal_error` | Internal server error |

All currency fields are in **USD**, rounded to **3 decimal places**.

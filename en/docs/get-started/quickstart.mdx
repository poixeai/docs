## Prerequisites

- A [Poixe account](https://poixe.com/dashboard)
- An [API key](https://poixe.com/token)

        ```bash
        go mod init main
        ```
      </Step>

      <Step title="Install the SDK">
        Install the OpenAI-compatible Go SDK (go-openai):

        ```bash
        go get github.com/sashabaranov/go-openai
        ```

      </Step>
